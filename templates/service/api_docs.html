REST API

API позволяет читать данные сервисной книжки в JSON. Авторизация — сессия Django: сначала войдите на сайте. Для клиента и сервисной организации выдаются только записи их машин. Менеджер видит все записи.

GET Назначение
/api/machines/ Машины
/api/maintenances/ ТО
/api/claims/ Рекламации
/api/machines/1/ Карточка по ID; аналогично для ТО и рекламаций

Фильтры

Передавайте ID записи справочника или пользователя в строке запроса:

  • Машины: machine_model, engine_model, transmission_model, steer_axle_model, drive_axle_model.
  • ТО: maintenance_type, machine, service_company. Параметр machine — ID машины (заводской номер указан в поле machine_number ответа).
  • Рекламации: failure_node, recovery_method, service_company.

order=asc — от старых к новым. По умолчанию — от новых к старым: по дате отгрузки, ТО или отказа соответственно. page=2 — следующая страница (25 записей на странице). format=json — явный выбор JSON.

Пример: /api/maintenances/?machine=1&order=asc&format=json

Списки возвращают объект {"count": 10, "next": null, "previous": null, "results": [...]}. Справочники вложены в записи и содержат ID, вид, название и описание. Даты имеют формат YYYY-MM-DD. Простой рассчитывается в днях, для незакрытой рекламации равен null.

Коды ответа

200 — успех; 400 — неверный фильтр; 403 — нет авторизации; 404 — запись не найдена или недоступна; 405 — метод записи не поддерживается. Изменение данных выполняется через формы сайта.
